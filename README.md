# SQL Fundamentals: SELECT &amp; Filtering

BrightLearn Data Analytics: SQL Foundations

## Overview
This repository contains 10 SQL queries and their expected tabular outputs for the BrightLearn SQL Fundamentals exercise, demonstrating foundational data retrieval and filtering techniques.

## Contents
* **`solutions.sql`**: SQL queries utilizing `SELECT`, `DISTINCT`, `ORDER BY`, `LIMIT`, and `WHERE` clauses (`AND`, `OR`, `NOT`, `IN`).
* **`outputs.md`**: Expected output tables extracted from the `employees` dataset.
